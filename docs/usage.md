# 凉澜丸（Femboy Pill）实验用法

## 安全提示（Safety Warning）
部分人群可能会对凉澜丸中的草本存在过敏反应。对于功能衰退型，阳虚（疲软、畏寒、萎靡）相关体质，凉澜丸可能加重体质不良状态。凉澜丸如与其它药物混用，可能导致副作用。长时间或大剂量使用凉澜丸，可能导致副作用。已知可能的部分副作用参考：关节酸痛、荨麻疹。

## 实验可选用法
* 事前两个小时服用。
* 事后立即服用。
* 饭前一小时服用。
* 饭后一小时服用。

## 实验可选用量
* 临时补充：一次1丸（9克），一日最多两次，每次间隔12小时
* 日常调理：一次1丸（9克），一日最多一次，连用不超过7天

## 实验经验提示
* 整丸或半丸吞服大蜜丸有窒息风险，可使用大蜜丸分药器将其分割成小粒，先后依次服用，亦可口含大蜜丸与饮用水，一起咀嚼至大蜜丸完全分散成小颗粒后吞服。
* 佐配淡盐水更佳。
